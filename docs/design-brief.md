# 山野取景

一处可持续维护的旅行入口，集中本次皖南四天摄影自驾和已归档的大兴安岭南线路书。主要路径为首页查找旅行 → 查看完整路书 → 返回首页。搜索与状态筛选用于快速找到项目。

用户已选择两份既有路书共同的暖纸色、深绿与摄影杂志风。视觉来源是 `reference/anhui-editorial.png` 与迁入的路书，不声称生成或选定了新的 AI 视觉方案。Creative Production 的画板工具在当前连接中缺少可传入的 action 参数，不能挂载；沿用已确认的真实来源继续制作。

首页以真实图像为主：方塘摄影师成片与阿尔山原路书的哈拉哈河图片，均保留原帖入口，不称为用户自摄。专业作品、发布日期、具体拍摄日的区别留在完整路书中。

## 样式与页面

- 背景沿用 `#f6f3eb`，文字和主操作使用 `#263b32`，秋色强调沿用铁锈色。
- 中文大标题使用系统宋体回退；正文使用内嵌 Manrope 与系统中文字体。大量留白、完整细边框，无粗单侧边条。
- 页头、左右分栏的当前旅行、两张摄影旅行项目卡、简短路书说明与页尾。
- 桌面并排，手机按阅读顺序排列；搜索与状态控件可触摸、可键盘操作。
- 访客页面只谈旅行，构建与部署说明放在 README。

## 发布边界

仅迁入明确必需的 HTML、脚本和图片。私有地图配置与临时平台签名不发布，原路书源目录不变。用户已明确要求上传 GitHub 并部署 GitHub Pages。
